# Marriage mod — rules

> Status: **data-only**. The gameplay rules are not designed yet; this mod
> currently only ships its data source (see README.md).

## Data rules

- Bride names come exclusively from
  `kingdoms-services/config/data/marriage/princesses.yaml` — no hard-coded
  names in code.
- Each civilization has at least 3 usable names.
- Names flagged `legendary` may be excluded from play by a mod setting if
  historical authenticity is required for a game mode.
