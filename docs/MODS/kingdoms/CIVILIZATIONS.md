# Kingdoms mod — Conditions d'obtention des civilisations

> Fourni par le game designer (Saison II). Une civilisation devient
> disponible pour un royaume quand sa condition est remplie ; les
> alliances s'actualisent **à la fin de chaque cycle** selon les
> mariages et les territoires conquis (décision D32) — on peut donc
> obtenir une civilisation puis la perdre.

## Notes de traduction (à valider par le game designer)

- **Types de maps** à saisir dans le catalogue admin : eaux, ouverte,
  nomade, désert/sable, montagne/colline, marais, lacs, dorée/or,
  start wall.
- **Conditions référentielles** à clarifier :
  - Hongrois « Appartenir au Royaume des HeN » — lien vers un nom de
    royaume fixé par l'admin ? Paramétrable ?
  - Shu/Wei/Wu « Posséder la civilisation Chinois » — déclenchement
    en chaîne dès que Chinois est débloqué.
- Les seuils (2, 3, 4, 5, 8, 10 maps, etc.) seront des valeurs de
  configuration modifiables par l'admin.
