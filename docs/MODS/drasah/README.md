# Drasah mod

The drasah mod adds a single slash command, `/drasah`, which greets the
invoking player with a medieval-flavored salute, in the player's
Discord locale (English or French).

## Purpose and goals

- Bring a touch of medieval roleplay to the server
- React to the invoking player by mention, so the greeting is personal
- Stay stateless: no stored data, no channels, no roles, no workflows

## Usage

```text
/drasah
```

Example answers (one is picked per invocation, stable per user):

- `Hail, <@123> ! Well met, noble soul, on this fine day !` *(en)*
- `Salut, <@123> ! Bien rencontré, noble âme, en ce beau jour !` *(fr)*
